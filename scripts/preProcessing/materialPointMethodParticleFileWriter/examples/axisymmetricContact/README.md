# Ordinary axisymmetric contact

Two equal elastic cylinders approach along their common axis, contact, and
rebound. Each cylinder has a CPDI core and a CPTI outer layer, all belonging to
the same body/contact group. Group 0 is the lower cylinder; group 1 is the upper
cylinder. ParticleColor only identifies bodies for plotting.

The cylinder radius is 10 mm, each length is 8 mm, and the initial axial gap is
2 mm. Initial speeds are +1 and -1 m/s. Density is 1000 kg/m3, Young's modulus
is 1 MPa, and Poisson's ratio is zero. Each body has volume
2.513274122871835e-6 m3 and mass 0.002513274122871835 kg. Their initial total
axial momentum is zero. The nominal free-flight contact time is 1 ms; the run
ends at 3 ms. This is a contact smoke case, not a calibrated material model.

## Run

Apply the ordinary-contact patch after the axisymmetric stage-1, jacketed-sample
and contact-friction build fixes, then rebuild GEOS. This example is installed
beside the other PFW examples.

From a fresh run directory, with the usual `userDefs_<username>.py` available
there or in the PFW directory:

```bash
export GEOS_EXECUTABLE=/absolute/path/to/rebuilt/geosx
/absolute/path/to/geos/scripts/preProcessing/materialPointMethodParticleFileWriter/examples/axisymmetricContact/runProblem
```

The runner generates the input, checks its particle geometry and labels, runs
GEOS on one rank, and plots the histories. Run it inside an allocation if the
site requires one. It does not submit a batch job or overwrite an existing run.
Use `--generate-only` to prepare inputs for the site's normal `srun` workflow.
The batch script generated by PFW uses `geosPath` from userDefs; ensure that it
names the same rebuilt binary.

To exercise FMPM(2), use another fresh directory and set:

```bash
export AXIS_CONTACT_UPDATE=FMPM
```

Default is `FLIP`. The selected setting is saved in `case.json` for subsequent
checks and plotting. After a scheduler run, execute `postProcess.py` from the
run directory to create `contactHistories.png` and `contactDiagnostics.json`.

## Expected behavior and interpretation

- The two bodies retain their approach velocity before contact, compress on
  contact, and subsequently separate. Inspect interface and outer-end tracers
  together to follow stress-wave travel.
- Radial/hoop motion should remain small for this zero-Poisson-ratio axial case.
  Circumferential velocity must remain zero.
- The contact plane should have axial normals, including close to the axis.
  The CPDI/CPTI seam within one body must not create a separate contact field.
- With friction zero, the law must not impose tangential sticking. A separate
  sliding test is needed to assess frictional behavior in full GEOS dynamics.
- Grid contact forces should be equal and opposite between fields at a node.
  Full-ring axial momentum should be conserved before particles reach an
  outer boundary. Contact and mapping can dissipate energy; exact energy
  conservation is not an acceptance criterion for this impact example.
- Tracer positions are particle centres. Their separation is not the surface
  gap; the plot deliberately labels it as tracer position.

The postprocessor checks finite, complete histories and zero circumferential
velocity, then produces diagnostics. It does not assert an unverified rebound
or stress tolerance. Check timestep/grid refinement and actual MPI runs on
the target build before treating the example as a numerical benchmark.

## Implementation scope

Ordinary contact uses the existing contact groups, normal-selection options,
gap modes and Coulomb law. `enableContact=1` enables force enforcement. Explicit
PFW surface normals/positions remain available; this example uses their
positions for gap detection and the default volume-based normal reconstruction.

The axisymmetric mapping stores `(G_r, G_y, T)` with `T=<N/r>` in its gradient
slots. The boundary-normal reconstruction now uses `V*(G_r+T, G_y)`; omitting
T produces a radial bias even in interior nodal supports. This is not an
extra circumference weight applied to prescribed unit normals. Ring mass and
momentum already supply the weight required by the contact force/impulse law.

Overlap correction, solver-reconstructed surface positions, nodal-area output,
DFG, CZ, moving walls and swirl remain unsupported. Supplied surface positions
or the existing centre-of-mass gap approximation can be used. The latter
remains an approximate contact-onset criterion, especially near the axis.
Particle splitting retains contact groups through the existing transfer; this
patch does not add splitting of active CZ state.

Do not simply put the jacketed-sample materials into separate groups and keep
the uniform pressure bath when modeling a sealed jacket: uniform confinement
can load newly exposed internal surfaces. Exterior-only pressure integration
is a separate follow-up.

## Local verification

From the PFW directory:

```bash
python3 tests/run_axisymmetric_contact_cpp_tests.py
python3 tests/run_axisymmetric_contact_writer_tests.py --output /tmp/axis-contact-writer
```

The C++ test compiles extracted production mapping, normal assembly, force and
FMPM impulse bodies with strict warnings and address/undefined-behavior
sanitizers. It checks mixed CPDI/CPTI axial, cylindrical and inclined interfaces,
interior cancellation, axis behavior, friction limits, separation/gap gating,
equal-and-opposite impulses and nonincreasing contact kinetic energy. The
writer test checks input restrictions and FLIP/FMPM generation at one and three
emulated ranks, including byte-identical particle files. Emulated collectives
are not an actual MPI simulation test.

These tests do not build the complete GEOS executable or run its timestep,
MPI migration/restart or GPU paths. The manual's LaTeX source is updated by the
patch; a compiled manual PDF is not included.
