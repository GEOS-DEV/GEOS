# Validation-scale legacy MPM examples

These problems are intentionally excluded from the fast verification suite. They
are useful validation or demonstration cases, but they are not currently small,
single-purpose tests with an analytical or ideal quantitative error metric.

To promote one back into verification, create a reduced folder-owned test with a
clean input, a runTest script, a postProcess script, setup/report assets, and a
fast analytical or ideal comparison.
