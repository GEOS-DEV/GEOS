# GEOS-MPM manual source bundle

This directory contains the LaTeX source for the GEOS-MPM manual.  The source is
organized so that technical prose and hand-maintained figures are editable in a
LaTeX editor, while code/schema-derived tables are regenerated by small Python
tools.

## Editable source

- `geos_mpm_manual.tex` is the checked-in top-level LaTeX driver.
- `tex/` contains human-maintained LaTeX prose, appendix wrappers, the preamble,
  and the title page.
- `figures/` contains human-maintained figures.  Replacing an image here is safe;
  `build_manual.sh` does not regenerate this directory.
- `linked_reports/` contains externally built report PDFs linked from the manual.

## Generated source

- `generated/data/geos_mpm_extracted.json` is extracted from the current GEOS
  checkout.
- `generated/tex/*.tex` contains generated tables and source/schema-derived
  reference appendices.
- `tools/extract_mpm_metadata.py` extracts metadata from the checkout.
- `tools/render_generated_tex.py` renders the generated LaTeX files.

Files under `generated/data/` and `generated/tex/` may be overwritten by the
manual build.  Do not put hand-maintained prose or figures there.

## Build

From this directory, run:

```bash
./build_manual.sh
```

By default the script uses the checked-in metadata JSON and refreshes only the
generated LaTeX snippets.  To re-extract metadata from the current checkout, run:

```bash
./build_manual.sh --refresh-data
```

With `--refresh-data`, the script determines the repository root from Git when
possible, otherwise from the current source-tree layout.  When the documentation
directory is outside the checkout, set:

```bash
GEOS_REPO_ROOT=/path/to/geos ./build_manual.sh
```

For compatibility with older workflows, `python3 make_manual.py` now refreshes
only the generated LaTeX snippets.  Use `python3 make_manual.py --refresh-data`
to refresh the intermediate metadata JSON as well.  It no longer rewrites the
manual driver or narrative files.
